# PSIRT Intake Portal

A capstone project that provides a structured vulnerability submission form and an internal analyst dashboard for triage, tracking, and status updates.

## Planned modules
- External submission form
- Validation and file upload handling
- SQLite data storage
- Internal dashboard
- Status workflow
- Metrics capture

## Tech stack
- Python
- FastAPI
- Jinja2
- SQLite
- Pytest
- GitHub Actions
- AWS Elastic Beanstalk
